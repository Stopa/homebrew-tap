# Stopa Tap

## How do I install these formulae?

`brew install stopa/tap/<formula>`

Or `brew tap stopa/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "stopa/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
